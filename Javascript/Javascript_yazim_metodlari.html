2. Internal Javascript yazımı :

Sadece yazıldığı sayfadan erişilebilen ve kullanılabilen javascript kodlarıdır. Genellikle "function" olarak sayfanın head kısmında yazılırlar. Eğer body içinde yazılmak istenirse, body'nin en alt kısmında yazılırlar.

3. External Javascript yazımı :

İstenilen tüm sayfalardan erişilebilen ve kullanılabilen javascript kodlarıdır. Genellikle "function" olarak .js uzantılı dosyaların içinde yazılırlar. Bu dosyaları sayfaya bağlamak için "head" kısmında ya da "body" nin en altında < script src="js_dosya_adi.js" > şeklinde bildirim yapılır. İstenlen sayıda .js dosyası bir html dosyasına bağlanabilir.
